The pattern

  1. Find the branching point

    Wherever a script or engineer picks ranks, threads, GPU or precision by rule of thumb.

  2. Run once, then ask

    model.observe(...) runs the job once and measures it; model.decide(state) returns a choice, a confidence and every option's probability.

  3. Act on confidence

    Above your threshold, apply the change automatically. Below it, hand the suggestion and alternatives to an engineer. STOP_TUNING means it thinks the config is already as good as it gets.

  4. Let it tune

    model.tune(...) loops decide → run → measure on this machine and keeps only changes that really made the job faster.
