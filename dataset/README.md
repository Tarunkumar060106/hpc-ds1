# HPC-DS1 benchmark dataset

Every row is one real run of one workload, at one size, with one setting (processes, threads, CPU or GPU, fp32 or bf16), on one machine. Nothing is simulated. Generated by `scripts/export_dataset.py`.

| Machine | CPU | GPU | Runs | OK | Out of memory | Failed / wrong | Skipped |
|---|---|---|---|---|---|---|---|
| rtx4050-laptop | 10 cores, 23.7 GB | NVIDIA GeForce RTX 4050 Laptop GPU (6.0 GB) | 3917 | 2942 | 1 | 583 | 391 |
| rtx5090 | 20 cores, 63.4 GB | NVIDIA GeForce RTX 5090 (31.8 GB) | 1056 | 868 | 0 | 188 | 0 |

## Workloads

| Workload | What it is | Size means |
|---|---|---|
| `gemm` | Dense matrix multiply | N (N×N matrices) |
| `fft` | 3D FFT (slab decomposition) | N (N³ complex grid) |
| `stencil` | 3D Jacobi stencil | N (N³ grid, 8 sweeps) |
| `spmv` | Sparse matrix-vector multiply | rows |
| `nbody` | N-body forces (all pairs) | bodies |
| `montecarlo` | Monte Carlo option pricing | paths (Asian option, 16 steps) |
| `mltrain` | Neural network training step | samples per step (MLP 256-1024-1024-10) |
| `server` | Backend request handling | requests per batch |
| `llm_train` | Language model training step (GPT-style) | sequences of 256 tokens per step (GPT, 63M params) |
| `cnn_train` | Image model training step (ResNet-18-style) | images per step (112×112, ResNet-18-style) |

## Columns

- `status`: `ok` (ran, result matches the fp32 reference), `wrong_result` (ran, but the answer differs beyond the workload's tolerance), `out_of_memory`, `failed` (any other error, e.g. no GPU version), `skipped` (not run: a CPU setting of a GPU-class workload expected to exceed a 60 s budget, from a real all-cores run, or a run that would not fit in free RAM; the reason is in `error`).
- `runtime_sec`: median wall time of the repeats; `gpu_peak_gb`: real peak GPU memory (above the card's memory, Windows spills into system RAM, so it can exceed it); `memory_gb`: host RSS of all processes plus GPU peak.
- `rel_error`: relative error of the result against the fp32 reference.
- Machine hardware is in `machines.json`.
